About

I am a PhD student in Computer & Information Sciences at Augusta University. My research are centered around programming languages, formal methods, memory saftey, type checking and program verification.

My work focuses on developing techniques and tools that improve the correctness, reliability, verification and security of software systems/program.

Before starting my PhD, I worked in cybersecurity for more than 3 years. I worked as a Solutions Engineer with experience in troubleshooting, debugging in customer support operations.

Research

My research interests lie at the intersection of programming language, formal verification, memory saftey and security.

Program Verification

Techniques for formally proving that programs satisfy desired properties and specifications.

Programming Languages

Programming language design, semantics, type systems, and tools for reasoning about programs.

Software Engineering

Methods and tools for improving software reliability, maintainability, and correctness.

Memory Safety & Security

Techniques for detecting and preventing memory-related vulnerabilities in software.
